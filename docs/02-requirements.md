# 要件

状態タグと ID の規則は `common/spec-conventions.md` を参照。
実機検証の前なので、全項目が【提案】である。

## 1. 入力

| ID | 要件 |
|---|---|
| RS-F-01 | カメラのライブ映像を解析できる。 |
| RS-F-02 | 標準カメラや他のカメラアプリで撮影した動画・写真を読み込んで解析できる。 |
| RS-F-03 | 露出を手動で設定できる端末では、露光時間を短く固定できる。 |
| RS-F-04 | 使うカメラ（レンズ）、解像度、フレームレートを固定できる。 |

RS-F-02 は、ブラウザから露出を制御できない端末（iOS など）のために併設する。どちらを主にするかは RS-Q-02。

## 2. 解析

| ID | 要件 |
|---|---|
| RS-F-10 | 画像上で、解析する帯（長方形の領域）を指定できる。 |
| RS-F-11 | 読み出し方向を自動で判定する。手動でも切り替えられる。 |
| RS-F-12 | 点滅モード：帯の中を、読み出し方向と直交する向きに平均し、明るさの波形を得る。 |
| RS-F-13 | 振動モード：行ごとに物体の輪郭（明暗の境目）の位置を検出し、変位の波形を得る。 |
| RS-F-14 | 波形から周期を求め、校正値を使って周波数を表示する。方法は自己相関またはフーリエ変換（RS-Q-11）。 |
| RS-F-15 | 複数コマの結果を平均して、ばらつきを抑える。コマをまたいで波形はつながない。 |
| RS-F-16 | 点滅モードで、点灯と消灯の時間の比を表示する。 |
| RS-F-17 | 帯を2つ以上置き、同じ画像に写った複数の物体（長さの違う2本の弦など）を同時に測れる。 |

## 3. 校正

`03-calibration.md` に詳細を書く。

| ID | 要件 |
|---|---|
| RS-F-20 | 既知の周波数の光または振動体を撮り、行の時間間隔 t_row を求める手順を備える。 |
| RS-F-21 | 校正値を、カメラ・解像度・フレームレートの組ごとに端末へ保存する。 |
| RS-F-22 | 校正していない状態では、周波数ではなく「1コマあたりの周期数」と「1周期の行数」だけを表示する。 |
| RS-F-23 | 校正の確かめとして、別の既知の周波数を測って誤差を表示する。 |

## 4. 表示

| ID | 要件 |
|---|---|
| RS-F-30 | 元の画像（帯の位置つき）と、取り出した波形を並べて表示する。 |
| RS-F-31 | 波形の横軸に、校正値から計算した時間の目盛りを付ける。 |
| RS-F-32 | 縞や波打ちのコントラストが足りないとき、光量不足や露光の長さの可能性を知らせる。 |
| RS-F-33 | 周期が測定範囲の下限・上限に近いとき、その旨を知らせる。 |

## 5. 出力

| ID | 要件 |
|---|---|
| RS-F-40 | 波形を CSV で、画面を画像で保存できる。 |
| RS-F-41 | 測定結果（周波数、条件のメモ）を一覧に記録できる。弦の長さと振動数のように、条件を変えた系列を作るため。 |

## 6. 非機能要件

| ID | 要件 |
|---|---|
| RS-N-01 | 処理はブラウザ内で完結し、映像を外部へ送信しない。 |
| RS-N-02 | 測定の目安は約100 Hz〜数kHz。実際の範囲は実機検証の結果で書き換える。 |
| RS-N-03 | 校正後の周波数の誤差は数%以内を目標とする（要検証）。 |
| RS-N-04 | タブ名やガイド文で結論を先に言わない。 |
| RS-N-05 | ボタンはタブレットやスマホで押しやすい大きさにする。 |
| RS-N-06 | 解析は帯の中の画素だけを使い、スマホでも重くならないようにする。 |
