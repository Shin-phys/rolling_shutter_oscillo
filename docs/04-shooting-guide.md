# 撮影条件と題材ごとの撮り方

全体が【提案】または【要検証】。実機検証を経て書き換える。

## 1. 共通

- スマホはスタンドで固定する。手ぶれ補正の影響を減らすため。
- 写真より動画のほうが自動合成の影響を受けにくい見込み（RS-Q-05）。
- 露出を手動で設定できるカメラアプリがあれば、シャッター速度を短くし（1/2000〜1/8000 秒）、感度を上げて明るさを補う。
- まず縞が写る向きを確かめ、測りたい物の向きをそれに合わせる。

## 2. 点滅モード

| 題材 | 撮り方 |
|---|---|
| 照明のフリッカー | 照明の真下に白い紙を置き、紙を画面いっぱいに撮る。照明そのものは写さない（白飛びするため）。 |
| LED の調光（PWM） | 調光できる LED ライトを暗めの設定にして白い紙を照らす。明るさを変えて、縞の明暗の幅の比を比べる。 |
| 基準光（校正） | マイコンで点滅させた LED で白い紙を照らす。 |

## 3. 振動モード

### 3.1 光源

- 振動体の後ろに、直流で点灯する明るいライトを置き、逆光のシルエットにする。
- 乾電池式の LED ライトは、明るさを下げると PWM で点滅するものがある。最大の明るさで使う。
- 白い紙をライトで照らして背景にしてもよい。

### 3.2 置き方

- 振動体の長い向き（音叉の腕、弦）を、読み出し方向に沿わせる。
- 振動の向きが、読み出し方向と直交するようにする。
- 振動体が画面の読み出し方向の大部分を占めるように近づける。周期の数が多いほど精度が上がる。

### 3.3 題材

| 題材 | 撮り方 | 注意 |
|---|---|---|
| 音叉 | 腕を逆光で撮る。たたいた直後に撮る。 | 振動が減衰するので、連続して数コマ撮って平均する。 |
| 弦（弦の固有振動の実験装置、モノコード） | 弦を逆光で撮る。弦をはじいた直後、または電磁的に駆動して撮る。 | 写る形は時間波形と振動の形の掛け合わせになる（`01-principle.md` の6節）。 |
| ギター | 弦を逆光で撮る。 | 複数の弦を同時に写すと、複数の帯で同時に測れる（RS-F-17）。 |

## 4. うまくいかないときの確認

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| 縞が写らない | 照明が直流点灯 | 別の照明か基準光を使う。 |
| 縞がぼけている | 露光が長い | 光を強くする。露出を手動で短くする。 |
| 波打ちに別の縞が重なる | 照らす光がちらついている | 直流点灯のライトに替える。ライトを最大の明るさにする。 |
| 写真だと縞が乱れる | 複数コマの自動合成 | 動画で撮る。HDR を切る。 |
| 周波数が毎回ばらつく | 校正値が合っていない、周期の数が少ない | 校正し直す。振動体を大きく写す。 |
