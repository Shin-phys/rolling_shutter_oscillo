# ローリングシャッター・オシロ（仮称）

## 1. 概要

スマホのカメラが画面を1行ずつ順に読み出す性質（ローリングシャッター）を逆用し、1コマの中の読み出し方向を時間軸として読むアプリ。
30 fps のカメラのまま、約100 Hz〜数kHz（目安）の点滅や振動を測る。

| モード | 撮るもの | 得られるもの |
|---|---|---|
| 点滅モード | 点滅する光に照らされた一様な面 | 光量の波形、周波数、点灯と消灯の時間の比 |
| 振動モード | 逆光のシルエットにした振動体（音叉の腕、弦） | 変位の波形、振動数 |

リポジトリ：https://github.com/Shin-phys/rolling_shutter_oscillo

## 2. 位置づけ

| 手段 | 得意な範囲 |
|---|---|
| 動画のコマ（波の3つの見方、トラッカー） | 数Hzまで |
| 本アプリ | 約100 Hz〜数kHz（目安） |
| マイク（音響スペクトルなど） | 可聴域全体。ただし他班の音が混ざる |

弦や音叉のように、動画のコマでは追えない速さが対象である。
光で測るので、他班の音に邪魔されず、全班が同時に測れる。

## 5. 引き継ぎ（次のチャットで最初にやること）

仕様を詰める前に、成立するかどうかを実機で確かめる（RS-Q-01）。アプリはまだ要らない。

1. 照明の下で白い紙を撮り、縞が写るかを見る（標準カメラの写真と動画の両方）。
2. 音叉を逆光で撮り、腕が波打って写るかを見る。
3. 写った縞の向きから、読み出し方向を確かめる（RS-Q-09）。
4. 写ることが確かめられたら、校正の基準（RS-Q-04）と入力の方式（RS-Q-02）を決める。
