# 参考：先行事例

ローリングシャッターを使った測定に前例があるかを調べた結果。
調査日は2026年10月15日。数回のウェブ検索による調査であり、網羅的ではない。

## 1. 結論

- 現象そのもの（ローリングシャッターで振動や点滅が縞や波打ちとして写ること）は広く知られている。
- フレームレートの限界を超える速さを、ローリングシャッターのゆがみから推定する工学的な研究もある。
- 今回の調査では、校正込みで周波数を数値として測る、教室向けのブラウザアプリは見つからなかった。見つからなかっただけで、存在しないとは言えない。

## 2. 前例があるもの

| 事例 | 内容 |

## 3. 参考：スマホで振動数を測る別の方法

ローリングシャッターを使わない方法には、教育用の報告が多い。

- マイクで音を録り、周波数を解析する方法（phyphox など）。
- 振動する棒の周波数をスマホで測る実験（González Delgado, González Rebollo, European Journal of Physics 37, 045701, 2016）。要旨ではローリングシャッターの使用は確認できなかった。 https://uvadoc.uva.es/handle/10324/16887

本アプリの利点は、音ではなく光で測るので、他班の音に邪魔されないことである。

## 4. 設計への示唆

- 現象が広く知られているので、「写ること」は成立する見込みが高い。課題は、周波数を数値にするための校正と、露光の短さの確保である。
- 新規性を主張する場面では、さらに調査が要る。
