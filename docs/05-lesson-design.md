# 授業での使い方

全体が【提案】。実機検証と実践を経て書き換える。

## 1. 題材の候補

| 題材 | 見るもの | 関連する単元 |
|---|---|---|
| 照明のフリッカー | 100 Hz の縞から、交流 50 Hz を確かめる。 | 交流 |
| LED の調光 | 点灯と消灯の時間の比（PWM）。 | 電気、探究 |
| 音叉 | 振動数の測定。刻印の値と比べる。 | 音 |
| 弦の振動 | 弦の長さ・張力と振動数の関係。 | 弦の固有振動 |

## 2. 弦の実験での利点

- 光で測るので、他班の音に邪魔されない。
- 全班が同時に、弦の長さや張力を変えて振動数を測れる。
- 長さの違う2本の弦を同じ画像に写せば、1回の撮影で比べられる（RS-F-17）。

## 3. 流れの案

### 3.1 導入：見えない点滅を見る

1. 教室の照明の下で白い紙を撮り、縞が写ることに気づかせる。
2. なぜ縞が写るのかを考えさせる（カメラの読み出しの仕組みの説明）。
3. 縞の数から、照明が1秒に何回明滅しているかを求める。
4. 交流の周波数と比べる。

### 3.2 展開：弦の振動数

1. 基準光で校正する（教員が1台用意し、各班が順に撮る）。
2. 弦の長さを変えて振動数を測り、記録する。
3. 長さと振動数の関係をグラフにする。
4. 張力を変えて同じことをする。

## 4. 準備物

- スマホを固定するスタンド
- 直流で点灯する明るいライト（振動体を逆光で照らす）
- 白い紙
- 校正の基準（`03-calibration.md`）
- 題材：音叉、弦の固有振動の実験装置、ギターなど

## 5. 時間

- 1回の授業（40分程度）で、導入（3.1）と弦の測定の一部が収まるかは要検証。
- 校正を毎回やる必要がないよう、端末ごとに校正値を保存する（RS-F-21）。

## 6. 生徒に見出させたいこと（教師用）

画面には出さない。

- 目には連続して見える光が、実は点滅していること。
- カメラの画像は、全体が同時に撮られているわけではないこと。
- 弦を短くする、または強く張ると、振動数が上がること。
